# 小芙

小芙是一只参考《原神》角色芙宁娜造型绘制的 ChatGPT 动态宠物。精灵图包含九组动作和十六个视线方向。

## Windows 桌面版安装

1. 在 GitHub 点击 **Code → Download ZIP**，下载并解压本分支。
2. 把 [xiao-fu](xiao-fu/) 文件夹复制到 `%USERPROFILE%\.codex\pets\`。如果设置了 `CODEX_HOME`，则复制到对应的 `pets` 目录。
3. 在 ChatGPT 桌面版打开「设置 → 宠物」，点「刷新」，选择「小芙」后输入 `/pet`。
